# 🤖 Teste API com IA Generativa

Este repositório tem como objetivo explorar o uso de IA Generativa no apoio à criação de cenários de teste para APIs.

## 🎯 Objetivo

Utilizar IA Generativa como suporte no processo de teste, auxiliando na elaboração de:

- Cenários de teste
- Casos positivos e negativos
- Validações de regras de negócio
- Sugestões de cobertura de testes

## 🧠 Contexto

A proposta deste projeto é demonstrar como a IA pode servir como ferramenta de apoio para profissionais de QA, tornando o processo de criação de testes mais ágil e estratégico.

Apesar desse apoio, a análise humana continua sendo essencial, principalmente para:

- Validar a coerência dos cenários
- Garantir aderência às regras de negócio
- Identificar riscos e lacunas
- Interpretar resultados com senso crítico

## 🛠️ Ferramentas

- Postman
- Swagger
- JavaScript
- Mocha
- Chai
- Node.js

## 🚀 Possíveis aplicações

- Testes manuais de API
- Testes exploratórios com apoio de IA
- Automação de testes
- Documentação de cenários

## ⚠️ Observação

A IA Generativa não substitui o conhecimento do QA, mas atua como uma grande aliada na criação de testes mais completos e eficientes.
